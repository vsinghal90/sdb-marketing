# SDB marketing

Marketing content for Shuddh Desi Bites.

- `reels/sdb-30s-reel.html`: the 30-second, 9:16 reel as an animated page. Open it in a browser, click **Start reel**, and screen-record it. Space pauses, R restarts, V hides captions, M mutes music, F goes full screen.
- The page plays an original dhol and tumbi track, built in code and timed to the scenes, so it needs no music licence. On the start screen you can load your own music file instead.
- `reels/sdb-30s-reel-music.wav`: the same 30-second track as an audio file, for video editors.
